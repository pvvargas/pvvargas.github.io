# Paulo Vargas portfolio

Static GitHub Pages website, Midnight & Lime edition.

## Publish or update

1. Open https://github.com/pvvargas/pvvargas.github.io
2. Upload `index.html` **and** the `assets` folder to the repository root. Keep the image filenames and folder structure unchanged.
3. Commit changes to the publishing branch (`main`, if that is your configured branch).
4. In repository Settings > Pages, confirm the source is `Deploy from a branch` and the folder is `/(root)`.
5. Visit https://pvvargas.github.io after deployment completes.

The original screenshots are available as compressed WebP images in `assets/`. The editorial thumbnails are CSS/SVG illustrations for now, rather than copyrighted article artwork. Article links, email and LinkedIn are real.

To preview offline, open `index.html` in a browser after extracting the ZIP.
